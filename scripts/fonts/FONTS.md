These are ASCII subsets of three fonts, all under the SIL Open Font License 1.1, which allows embedding them in the SVG graphics:

| File | Font |
| --- | --- |
| display.woff2, display-italic.woff2 | Instrument Serif (Instrument) |
| sans-400.woff2, sans-600.woff2 | Inter (Rasmus Andersson) |
| mono.woff2 | JetBrains Mono (JetBrains) |

The source files came from the `@fontsource` npm packages and were subset with `subset-font`.
